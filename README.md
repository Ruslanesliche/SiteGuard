# SiteGuard

SiteGuard — отдельное веб-приложение для пассивного аудита безопасности сайтов и публичных GitHub-репозиториев. Оно не эксплуатирует уязвимости и не изменяет проверяемые ресурсы.

## Что проверяется

- HTTPS, HSTS, CSP, CORS и защитные HTTP-заголовки
- cookies, кэширование, смешанный контент, формы и внешние ресурсы
- базовая приватность, доступность, SEO и PWA-настройки
- публичный код GitHub: случайно опубликованные секреты, опасные API, CI-права и конфигурация
- точные версии npm-зависимостей через OSV

В отчёте есть оценка, приоритеты, доказательства, рекомендации и экспорт в JSON.

## Безопасность сканера

- разрешены только публичные HTTP/HTTPS-адреса;
- локальные, приватные и служебные IP-диапазоны блокируются до запроса и на каждом редиректе;
- объём ответа, число редиректов, время запроса и частота проверок ограничены;
- GitHub проверяется только через публичные API и по зафиксированному commit SHA;
- найденные значения секретов никогда не возвращаются в отчёт;
- результаты не сохраняются на сервере.

## Отдельный активный режим

Раздел `/active` запускается отдельно от пассивного сканера. Перед проверкой владелец
размещает одноразовый токен в `/.well-known/siteguard-verification.txt`. После
подтверждения SiteGuard выполняет пять ограниченных запросов GET/OPTIONS и проверяет:

- безопасное отражение инертного HTML-маркера;
- признаки ошибок SQL после диагностической кавычки;
- CORS и объявленные HTTP-методы;
- видимые CSRF-токены в формах;
- признаки rate limiting у публичной формы входа.

Режим не отправляет пароли, не выполняет POST/PUT/PATCH/DELETE, не загружает файлы,
не обходит авторизацию и не эксплуатирует найденные признаки.

## OpenAPI и права доступа

Раздел `/active/api` запускается отдельно внутри SiteGuard. После подтверждения
домена он импортирует OpenAPI 3.x или Swagger 2.0 в формате JSON с того же домена.
Для выбранного GET-маршрута выполняется ограниченная матрица доступа:

- запрос без токена;
- аккаунт A к своему и чужому тестовому объекту;
- аккаунт B к чужому и своему тестовому объекту.

Модуль ищет признаки BOLA/IDOR, не выполняет изменяющие запросы, не сохраняет
Bearer-токены и не включает их в отчёт. Используйте только специально созданные
тестовые аккаунты без реальных персональных данных.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
corepack enable
pnpm install
pnpm dev
```

Проверка проекта:

```bash
pnpm run typecheck
pnpm test
```

## Ограничения

SiteGuard выполняет пассивную автоматическую проверку и не заменяет ручной pentest, анализ бизнес-логики или аудит закрытого исходного кода. Проверяйте только ресурсы, которыми владеете или на проверку которых получили разрешение.
