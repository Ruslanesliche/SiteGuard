# SiteGuard

SiteGuard — отдельное веб-приложение для пассивного аудита безопасности сайтов и публичных GitHub-репозиториев. Оно не эксплуатирует уязвимости и не изменяет проверяемые ресурсы.

## Что проверяется

- HTTPS, HSTS, CSP, CORS и защитные HTTP-заголовки
- cookies, кэширование, смешанный контент, формы и внешние ресурсы
- базовая приватность, доступность, SEO и PWA-настройки
- публичный код GitHub: случайно опубликованные секреты, опасные API, CI-права и конфигурация
- точные версии npm-зависимостей через OSV

В отчёте есть оценка, приоритеты, доказательства, рекомендации и экспорт в JSON.

## Безопасность сканера

- разрешены только публичные HTTP/HTTPS-адреса;
- локальные, приватные и служебные IP-диапазоны блокируются до запроса и на каждом редиректе;
- объём ответа, число редиректов, время запроса и частота проверок ограничены;
- GitHub проверяется только через публичные API и по зафиксированному commit SHA;
- найденные значения секретов никогда не возвращаются в отчёт;
- результаты не сохраняются на сервере.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
corepack enable
pnpm install
pnpm dev
```

Проверка проекта:

```bash
pnpm run typecheck
pnpm test
pnpm run build
```

## Ограничения

SiteGuard выполняет пассивную автоматическую проверку и не заменяет ручной pentest, анализ бизнес-логики или аудит закрытого исходного кода. Проверяйте только ресурсы, которыми владеете или на проверку которых получили разрешение.
